📖 Integration Guide

1. Device Pairing (Required)

HeyClawy authenticates with OpenClaw via ED25519 device keys. On first boot, the device generates a keypair and stores it in NVS.

To pair:

  1. Note the Device Key shown above (or from serial log at boot: Device identity: <hex>)
  2. On the OpenClaw machine, run:
    openclaw device approve <device-key-hex>
  3. The device will auto-connect on next WebSocket attempt (every 5s)

⚠️ If using token auth instead of device keys, paste the token in the Token field above.

2. STT Server (Required for voice)

HeyClawy sends recorded audio to a faster-whisper STT server for transcription.

Setup on the OpenClaw machine:

  1. pip install faster-whisper flask
  2. Create ~/.openclaw/tools/stt_server.py (a Flask server wrapping faster-whisper on port 5051)
  3. Start: python3 stt_server.py &
  4. Auto-start (crontab): @reboot sleep 10 && cd ~/.openclaw/tools && python3 stt_server.py &

Health check: curl http://<host>:5051/health → {"status":"ok"}

⚠️ The STT model downloads ~500MB on first run. Use "small" for quality, "tiny" for speed.

3. TTS Server (Optional — for voice responses)

For audio playback of OpenClaw responses, an EdgeTTS-compatible server is needed.

Quick setup with Docker:

docker run -d -p 5050:5050 travisvn/openai-edge-tts

Configure host/port in the Services tab.

4. LAN Security (if needed)

OpenClaw may block non-TLS connections. If you see SECURITY ERROR: ws:// to non-loopback:

  1. In ~/.openclaw/openclaw.json, add: "security": {"allowPlaintextLan": true}
  2. Or set env: OPENCLAW_ALLOW_PLAINTEXT_LAN=1
  3. Restart OpenClaw gateway
